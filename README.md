# LinkBlock

受经典画线圈地玩法启发的单关卡网页小游戏。沿已占领区域的边缘移动，按住空格进入危险区画线，再接回安全区完成占领；所有普通敌人和 Boss 所在的区域都保留为危险区，占领内部面积达到 75% 即可获胜。三条生命耗尽则结束。风景图为项目内置 SVG，无需外部图片服务或后端。

## 开发

需要 Node.js 22.12+（本环境已验证 Node.js 24）。

```sh
npm ci
npm run dev
```

## 操作

| 操作 | 按键 |
| --- | --- |
| 四方向移动 | 方向键 / WASD |
| 画线 | 按住空格并移动 |
| 快速收线 | 未闭合时松开空格 |
| 暂停 / 继续 | P / Escape |
| 重新开始 | R |

触屏窄屏提供方向按钮与画线开关。普通移动只能沿场地外框和占领区域与危险区相接的边缘行走，不能穿过已占领区域内部，即使按住画线键也不例外。圈地闭合后停在连接点，重新按方向继续沿边缘移动。键盘与触屏均按帧经过的时间连续移动，速度为每秒约 256 个画布像素；按键按下后在下一帧开始移动，松开方向键即停（自动收线除外），转向可发生在任意坐标。角色中心、边界和轨迹使用同一套坐标，不再使用格子、格点或步进吸附。

画线不能自交；画线尚未闭合时松开空格，角色会以画线速度的三倍沿原路连续退回，轨迹随线头逐段缩短，直到回到最初离开边界的点。回收无需按方向键，途中再次按空格或方向键不会中断返程；返回后停在起点，重新按方向键开始下一次移动。回收不增加领地或得分，尚未收掉的线仍可被敌人击中。触屏关闭画线开关也会触发回收。暂停会冻结回收，继续后自动完成返程。受击后本次轨迹清空，返回出发点；闪烁恢复期间只能沿安全边缘移动。窗口失焦或切换标签页会自动暂停。音效默认关闭，可在侧栏开启。

## 访客与 Boss

所有敌人只在未占领区域内沿自己的轨迹独立移动，不追踪玩家，也不沿玩家画出的线移动；身体遇到外框或新圈地边界会反弹。

| 访客 | 移动 | 标识 |
| --- | --- | --- |
| 疾行 | 快速直线，边缘反射 | 珊瑚红箭头 |
| 环游 | 较慢的连续环绕，碰边反弹后继续环绕 | 淡紫圆环 |
| 折光 | 中速移动，每约 0.72 秒交替折转 | 浅蓝菱形 |
| 湖心守卫 Boss | 缓慢直线反射，每 5 秒释放八向散射 | 橙色六边形 |

Boss 释放前约 0.85 秒显示蓄力圆环和八向提示。子弹不受占领边界阻挡，可以穿过已揭开的区域；它们会击中玩家（包括安全边界上的玩家）和未闭合的线，飞出场地后自动清理。受击后仍有 1.5 秒保护时间。暂停会冻结敌人、蓄力和子弹；重开会重置全部状态，胜负确定后清除攻击。

完成一条切线后，只有不含任何敌人身体的部分才会被占领。如果两侧都有敌人，两侧都保留为危险区，切线成为可行走的新边界；继续切分即可逐步占领空白区域。圈地判定只考虑敌人身体，不将子弹视为区域占用者；成功圈地不会清除子弹。敌人短尾迹仅表示它们刚走过的路线，不能供玩家行走或收线。

## 验证与构建

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

已有 Chromium 时可使用 `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`。端到端测试自动启动开发服务器，验证连续移动和转向、贴线对齐、圈地局部白光与粒子、三种普通敌人与 Boss 图鉴、Boss 预警及八向弹幕、暂停恢复、重开、音效开关、窄屏触控及减少动态效果。`npm run build` 执行 TypeScript 检查并将静态站点输出到 `dist/`；`npm run preview` 可预览产物。

## 结构

- `src/engine.ts`：连续坐标状态机，包含沿线移动、多边形切分圈地、敌人反弹、线段碰撞和胜负判定。
- `src/enemies.ts`：三种独立运动规则、Boss 本体运动和有长度上限的尾迹。
- `src/attacks.ts`：可替换的 Boss 技能、通用攻击物生命周期与八向子弹实现。
- `src/render-enemies.ts`：敌人形状、尾迹和 Boss 蓄力绘制。
- `src/geometry.ts`：线段距离、边界射线、面积与多边形切分；不使用栅格或像素掩码判定领地。
- `src/effects.ts`：主题配置与圈地效果接口。静谧之湖主题先让新占领区域显白约 0.23 秒，再播放约 1 秒的湖光粒子消散；粒子上限为 180 个。系统启用减少动态效果时使用低强度淡出，不播放粒子。
- `src/main.ts`：Canvas 绘制、键盘与触屏输入、界面、可选 Web Audio 音效。
- `src/style.css`：响应式深色街机界面。
- `public/landscape.svg`：随领地揭开的原创风景插画。

第一版包含一个关卡、三种普通敌人和一个 Boss、三条生命与局内计分；尚未加入多关卡、存档或排行榜。

## 替换主题效果

`GameTheme.createCaptureEffect(region, reducedMotion)` 接收刚占领的多边形，返回实现 `update(seconds)`、`render(context)` 与 `finished` 的 `CaptureEffect`。绘制上下文使用与角色、边界一致的世界坐标。可在 `src/effects.ts` 新建主题并在 `src/main.ts` 选择它；主题可替换风景、边界颜色、轨迹颜色和整个圈地效果，无需修改圈地规则。重新开始会清除效果，暂停会冻结效果，胜利弹窗会等待最后一次效果结束再显示。

## 替换 Boss 技能

`new Game(width, height, { createBossAttack: () => new MySkill() })` 为每局创建独立的 `BossAttack`。技能提供 `name`、`warning`（0–1 蓄力进度）和 `update(seconds, context)`；`context` 提供 Boss 当前位置、场地尺寸、`spawn(hazard)` 和 `cast()`，没有玩家追踪逻辑。

`AttackHazard` 约定攻击物的 `update`、`expired`、`hitsPlayer(from, to, radius)`、`hitsTrail(trail, radius)`、`onHit()` 和 `render()`。子弹、近战扇形、冲击波等均可实现这一接口，游戏主循环无需判断攻击类型。移动攻击需在碰撞方法内覆盖一帧经过的路径；本帧碰撞检查完毕后移除 `expired` 攻击物。默认 `Projectile` 使用扫掠碰撞，避免高速子弹穿过细线或边界上的玩家。近身技能的测试实现验证了非子弹攻击同样可用。

活动攻击物上限为 128，每个敌人的尾迹上限为 18 个采样点，过期攻击每个物理子步都会移除。更换关卡可通过 `GameOptions.enemies`、`boss` 和 `createBossAttack` 配置生成内容；若只需身体接触攻击，可提供 `() => ({ name: '普通攻击', warning: 0, update() {} })`，不生成额外攻击物。主题也可在 `GameTheme.createBossAttack` 提供技能工厂，当前湖主题已通过该入口创建八向散射；圈地视觉效果仍通过独立的 `createCaptureEffect` 替换。

## 发布到 GitHub Pages

仓库内置 `.github/workflows/deploy.yml`。首次发布时，在 GitHub 仓库的 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。推送到 `main` 会自动安装依赖、运行规则测试、构建并部署静态站点，也可以在 **Actions → Deploy LinkBlock to GitHub Pages → Run workflow** 手动运行。若启用 Pages 之前的部署已失败，启用后重新运行该工作流。

部署成功后，默认访问地址为 <https://roukeiyu.github.io/LinkBlock/>（以 GitHub 部署结果显示的地址为准）。资源使用相对路径，支持 GitHub Pages 项目目录。Actions 构建失败时不会部署新的版本。
