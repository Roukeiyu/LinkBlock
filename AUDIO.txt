封林 audio
============

Background music
----------------
Each level loops one track. Levels 1–4 retain the owner-supplied music.
Levels 5–10 use Suno recordings generated for the owner and prepared as loops. The game
prefers the Opus .ogg and falls back to .mp3. A file is downloaded only
after the first tap or key press, and only for the level being played.

  Source: https://suno.com/song/2abb682a-b45f-4a66-ab71-70fe624b08ee

These six recordings are Suno-generated, not programmatically synthesized and
not covered by the CC0 sound-effect dedication. Generation dates were not
included with the downloaded source metadata. Original MP3 downloads are
retained separately; source SHA-256 hashes and output measurements are in
public/audio/suno-v1-sources.json.

Processing: trim detected terminal silence below -45 dB, overlap the final and
initial 3 seconds with an equal-power crossfade, and rotate the loop to start
at the original 3-second point. Two-pass loudness normalization targets -20 LUFS
with a -2 dBTP ceiling, followed by stereo 48 kHz Opus (96 kbps) and MP3 (160 kbps)
exports. A 10 ms de-click envelope at each endpoint prevents codec-boundary
clicks without a musical fade-out. Final measurements are recorded per encoded format in the manifest.
No pitch or tempo correction is applied. Musical phrasing, instrumentation,
absence of voices and subjective loop quality have not been audition-verified;
automated decoding, loudness and playback checks do not establish those facts.

Rebuild from approved original downloads and their sources.json:
  python3 scripts/prepare-suno-audio.py /path/to/originals
Requires Python 3, NumPy and ffmpeg/ffprobe with libopus/libmp3lame. Normal game builds
use the committed exports and need neither Python nor ffmpeg. New -suno-v1
resource names avoid stale cached audio; levels 1–4 and sound effects are unchanged.

Legacy unused audio retained for history: autumn-ride was the owner's former
level-5 recording. sunken-court, fox-shrine, aurora-throne, dusk-belfry and
ember-crown (without -suno-v1) are the former synthesized expansion loops,
rebuildable with scripts/build-expansion-assets.py --music. They are no longer
selected by src/levels.ts. The synthesis script does not overwrite Suno exports.

Levels 11–20 — one original loop per theme
-------------------------------------------
Each later chapter has its own stem, stored on the theme row in src/levels.ts.
Swapping two themes (for example 紫藤画舫 and 翠角神林) moves the music with
the theme. There is still one looping track per level and no separate boss or
phase recording; the existing mood control only changes playback gain.

  蛛丝绣楼 silk-tower            Suno recording, looped like levels 5–10
  紫藤画舫 wisteria-boat         Suno recording, looped like levels 5–10
  金沙斗场 golden-arena          Suno recording, looped like levels 5–10
  翠角神林 jade-forest           Suno recording, looped like levels 5–10
  钟械秘阁 clockwork-archive     Suno recording, looped like levels 5–10
  琥珀龙窟 amber-cave            Suno recording, looped like levels 5–10
  月蚀歌剧院 eclipse-opera       Suno recording, looped like levels 5–10
  雷纹天城 thunder-citadel       Suno recording, looped like levels 5–10
  星陨神座 fallen-star           Suno recording, looped like levels 5–10
  万象封门 myriad-gate           Suno recording, looped like levels 5–10

All ten stems for levels 11–20 are the owner's Suno recordings, matched to the
theme name rather than the current level number. The six newest were picked
and downloaded on 2026-11-25 from the private Suno playlist "LinkBlock BGM"
(雷纹天城 is the second, storm-electronica generation; the earlier march-style
takes were rejected). Source MP3 SHA-256 hashes are in public/audio/campaign-11-20.json.
They use the levels 5–10 chain: terminal silence below -45 dB trimmed only at
the end, a 3 second equal-power crossfade, a 10 ms endpoint de-click, -20 LUFS
with a -2 dBTP ceiling, 48 kHz stereo Opus at 96 kbps and MP3 at 160 kbps, and
no cover art or other metadata. scripts/compose-campaign-music.py no longer
renders any stem and does not overwrite the Suno stems. Measurements and hashes: public/audio/campaign-11-20.json.
Subjective listening of the processed joins has not been verified.

Sound effects
-------------
Every effect (drawing, capture, the seal, the boss, UI clicks) is still
synthesized at runtime by src/audio.ts with the Web Audio API. Those
effects are original and dedicated to the public domain under CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/


Dedicated main menu — 谜趣之门 Curious Threshold
------------------------------------------------
Approved by the owner after audition on 2026-11-12.
Source: https://suno.com/song/9ed7e5b5-0983-4857-8169-c9fc50ddc778
The Suno original is 148.584 seconds. curious-pages-suno-v1 is a 145.56-second
loop using the same 3-second crossfade and normalization procedure described
above. Output metrics and hashes: public/audio/menu-suno-source.json.
The original has owner listening approval; the processed join has objective
decoding/boundary checks, not a claimed subjective listening review.
Rebuild: python3 scripts/prepare-menu-audio.py ORIGINAL_MP3 SOURCE_URL

The title screen and its settings/gallery use this dedicated track; starting
or resuming a level selects that level's music, and returning home restores
the menu track. Playback still requires the first user gesture and honors
music mute, remembered volume and tab visibility. No level audio is replaced.
