# 密卷 · 界面提案（第三稿）

第二稿把界面收成干净的书页，留白多，物件少。这一稿仍是书，但改成一册用旧了的魔法书：布局和控件的形状都换过，不是在空白页上加一层噪点。

游戏脚本、样式、原画和音乐都没有改。现况截图在 `captures/current/`。第二稿截图留在 `captures/plain/`，用来对照。这一稿在 `captures/proposed/`。

## 怎么组织

每一屏共用一套书的骨架，再按屏分配不同的物件，避免每页都堆满同一批装饰。

全册都有：深色皮封面和一道金线压印、装订缝、浅色纸、一条现成的织纹书签、页角一枚火漆（只在目录页，且不能点）。

各屏另外使用的东西：

| 屏 | 控件形态 | 装饰放在哪 |
| --- | --- | --- |
| 主菜单 | 叠起来的纸签，主操作是带火漆的大签 | 标志后面的符环、花边分隔、斜贴的「正在解封」纸条、二十个印记排成的名册 |
| 设置 | 别在目录上的一张条子，略微转一点 | 条子上方一枚火漆钉 |
| 选关 | 每关一张小票：圆印序号、关名、色线、状态戳 | 卷名旁用现成的墨线花边 |
| 局内 | 顶上是双线题签；右侧是横格页边栏 | 场地只用现成的花边框。框内是墨线示意 |
| 手机局内 | 题签保留生命和分数；页脚是一枚小符环 | 花边框变窄，不占半屏 |
| 结算 | 夹进书里的另一张纸，四边虚线，三格成绩 | 火漆在标题上方 |
| 图鉴 | 缝线目录；图版四角有卡纸角 | 未解锁的一张横贴封条 |
| 审阅 | 突出的页签 | 与图鉴相同的装裱，斜线只表示原图位置 |

边注、符环、花边、书签都不能点。能点的只有纸签、票、页签和写了字的墨框按钮。

## 可读与场地

字仍然是宋体，颜色 `#1a120c`，落在 `#f6efe2` 的纸上。目录签标题 18px，选关关名 15px，说明不浅于 `#5e4636`。纸签高度至少 58px，票至少 46px。

局内装饰收在花边框和右侧页边栏。栏宽 156px。手机上这栏收起，触控是 92px 的符环，写着「按住画线，松开收线」。场地保持 3:2，图下写「场地示意，不是正式关卡画面」。

进度、分数、生命、收录数都标「示例」。
