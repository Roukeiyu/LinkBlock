# 书页 · 界面提案

这是第二稿。上一稿把书留在背景里，控件改成深色漆面，和「书、纸、装订、火漆」不一致，这一稿整本换掉。游戏脚本、`src/style.css`、`public/` 里的图和声音都没有改。现况记录仍在 `INVENTORY.md`。

打开 `index.html` 逐页看。`compare.html` 左边是线上截图，右边是这一稿。

## 意图

界面本身就是一册可以操作的古籍，不是铺在旧书上的另一套仪表。

每一屏都有同一件东西：左侧布面书脊和凸起的装订带，中间一页浅色纸，右侧一叠切齐的书口。纸用现有的细纤维纹，压得很淡，不铺焦黄的撕边。字是近黑的墨，落在浅纸上。火漆只押在主动作、生命和书签上。烫金不铺成大块渐变，只偶尔出现在已经做好的标志里。

关卡仍是那二十处。钟械秘阁、琥珀龙窟、月蚀歌剧院、雷纹天城、星陨神座、万象封门在选关的卷二。关卡之间的差别是页边上的一条墨色，不是整页换皮。

## 原则

- 书脊、纸页、切口、墨、火漆在每个界面里都能指出来。
- 信息靠字号、墨色深浅和一条横线分开，不靠把整页染成羊皮色。
- 中文用宋体。标题 17px 起，正文 15px，说明不浅于 `#6b5344`。字距只在两三个字的眉题上略宽，句子不拉开。
- 主操作是一枚火漆配一行墨字，像目录里被钤过印的条目。其余条目是底线和点线引导，没有色块按钮。
- 手机上书脊收到顶上一窄条。局内把高度让给图版，触控是页脚一枚小圆印，不占半屏。
- 进度、分数、生命都标「示例」。局内图形标「场地示意」。色块和斜线框不是新的角色图。
- 正式原画、音乐、关卡数据和玩法都不在这一稿里改。确认之前不接入游戏。

## 字体与间距

字体只加载 `Noto Serif SC` 500 和 600。回退 `Songti SC`、`STSong`、`SimSun`。

| 角色 | 字号 | 字距 |
| --- | --- | --- |
| 页题 | 30px / 600 | `0.08em` |
| 火漆主条目 | 22px / 600 | `0.12em` |
| 目录条目 | 17px / 600 | `0.06em` |
| 标语 | 18px，手机 15px | `0.18em`，手机 `0.12em` |
| 正文与按钮 | 15px | 不额外拉开 |
| 页脚示例 | 12–13px | `0.04em`，颜色用火漆深色 `#6e2822` |

## 组件

**书。** 书脊写竖排书名，三条装订带。纸页左侧有装订槽的阴影。书口是四条细线，表示切齐的纸边，不是撕口。右上一条火漆书签，写着「示例」。

**主条目。** 火漆图加墨字，底下一道实线。悬停只铺一层很淡的朱红。按下下移 1px。

**目录行。** 题名、点线、短注。选关把点线换成首领名和状态。

**进度。** 二十根墨线。已解开的升高，当前这一关换成火漆。局内净化是上下两道墨线夹着的一条填色，75% 处一根火漆刻度。填色是墨与关卡色对半相混，看起来仍是墨，不是亮条。

**生命。** 三枚现成的火漆小图。用掉的一枚只留淡影。

**设置。** 写在目录同一页的下半，不另开深色层。开与关是两个字，按下的那个描火漆边。音量是一条细线。

**结算。** 书页之上再叠一小张同样的纸，不是暗色玻璃。火漆在上，标题居中，净化、得分、用时分成三格。页脚写明数值是示例。

**图鉴与审阅。** 图是贴进书里的图版：细墨框、浅纸底。未解锁的一格只放一枚火漆。审阅的斜线框写「原图位」。人形 / 魔物是页眉上的签，不是贴边的深色坞。

**手机触控。** 一枚 84px 的圆印，印心是火漆点。下面一行字：按住画线，松开收线。

**焦点。** 2px 墨色外框。动作 160ms。系统要求减少动效时不再过渡。

## 各屏

演示进度是同一条故事，并且每页都标了示例：前十六关已解开，正在第十七关月蚀歌剧院。图鉴打开琥珀龙窟，通关和满血已收入，击败首领未解开。胜利是打完第十七关之后，下一关为雷纹天城。这些数字不是存档。

**主菜单。** 左页是标志、标语和正在读的一关。右页是目录。窄屏改成先左页、后右页，仍是同一张纸。

**选关。** 左页卷一，右页卷二，二十关同时在目。手机改为向下接卷二。进行中的一行铺淡朱红。未解锁用淡墨，仍能读出关名。

**局内。** 页眉是关名、净化、火漆生命和分数。中间的图版尽量占满剩余纸面。图是墨线示意图：已圈区域、虚线、火漆点表示所在位置。图下写「场地示意，不是正式关卡画面」。手机把书脊压到 34px，圆印留在页脚，图版吃掉中间的高度。

**结算。** 胜利、失败、暂停共用这一张夹页，只换火漆和句子。句子仍是现在游戏里的中文。

**图鉴。** 左边是关名目录，右边一次三张图版。

**审阅。** 信息还是奖励、敌人、类型、形态、三列图。换的是纸、书脊和墨字。构建脚本和原图路径都不动。
