封林 — Level 6–10 artwork
=========================

The expansion's active version 3 illustrations were redrawn specifically for this game:
6 海妖 / 沉潮王庭, 7 狐妖 / 狐火神社, 8 冰霜巨人 / 极光冰座,
9 石像鬼 / 暮钟圣城, and 10 炎魔 / 熔冠终庭.

The original first five chapters are the style references: mature, strongly
built men, natural body hair, fine painted contours, atmospheric moonlight and
practical cloth/leather costumes. The new cast varies facial structure, hair,
facial hair and expression while retaining that established visual direction.
The sea man has restrained iridescent scale patches on exposed skin; the blond
frost giant has a subtle icy-blue complexion; the lava warrior has short black
hair and beard, dark red skin, swept-back black horns and sparse ember fissures.
Within each chapter all three illustrations preserve the same character.
Clear / ninety / perfect progress from layered outerwear to lighter outfits
and relaxed poses. Updated v4 rewards give the sea man rope-belt sailor trousers,
the fox spirit tied charcoal hakama trousers, the frost giant a fur-edged waistwrap
and one shin guard, the stone guardian deep-plum trousers with a diagonal sash
and bronze clasps, and the lava warrior worn black leather trousers with bronze
fastenings. The frost giant's ninety vest is fully open, and his perfect portrait
has a bare torso. These edits retain the v3 character identities and settings.
The stone guardian sits upright holding a city key, with both feet lowered;
the other characters keep their existing poses.

Each public/levels/{6,7,8,9,10}/v3/ directory contains:
- restored.webp: the complete character and scene, 1536 × 1024.
- ninety.webp: a separate 90% completion character illustration.
- perfect.webp: a separate perfect completion character illustration.
- mask.png: image-generated character segmentation, normalized to black/white
  with the same threshold used by the game, in the same scene coordinates,
  with small enclosed generation artifacts closed and a three-pixel edge guard;
  used by the existing 60% character / 40% background progress calculation.
- sealed.webp: the exact scene with a desaturated dusk filter, opaque character
  veil and subdued violet rim, using the same mask as completion scoring.
- portrait.webp / portrait-sealed.webp: matching character portraits.
The expansion's six enemy sprites per chapter remain in their v2 directories.
The active perfect rewards for chapters 6 through 10, plus chapter 8's ninety
reward, now use their v4 directories. Other reward files still use v3.
src/levels.ts selects the active image for each tier.

Illustrations, sealed scenes and portraits are committed as WebP. The filters
are rasterized during asset preparation so gameplay draws ordinary cached images
without repeatedly evaluating large SVG filters. No remote image service is used.

art/expansion/v3-sources.json records the generated source PNGs. Run
node scripts/pack-character-art.mjs /path/to/generated_images to encode the
three illustrations and normalize their masks; it requires ffmpeg/ffprobe.
For the six updated reward illustrations, use the separate reward-only manifest:
node scripts/pack-character-art.mjs /path/to/generated_images art/expansion/v4-reward-sources.json
This encodes only the listed v4 rewards, without regenerating main illustrations,
character masks, sealed scenes or portraits.
The source images remain intact. The committed WebPs/PNGs are sufficient for
all ordinary builds; original generation files are not a build dependency.

scripts/build-expansion-assets.py prepares matching seal and portrait SVGs from
the committed restored.webp and mask.png files (Python 3 standard library only).
The intermediate files are written to the ignored art/expansion/build/ directory.
Then run scripts/bake-expansion-art.mjs with Node to render those files into the
runtime WebP assets. It uses Playwright Chromium (or CHROMIUM_PATH) and ffmpeg.
Pass --music to build-expansion-assets.py to intentionally rebuild the existing
music loops; that optional operation also requires NumPy and ffmpeg. Illustrations and segmentation are
generated source artwork and are not recreated by this script.

art/expansion/{6,7,8,9,10}-sprites.webp preserve the generated transparent
3-column by 2-row sprite atlases. node scripts/pack-enemy-sprites.mjs extracts
each cell to its alpha bounds and packages the six runtime WebP sprites; it
requires ffmpeg and ffprobe. Atlas order: three straight-moving looks, orbiter,
zigzag, boss. The script maps that order to the renderer's legacy look keys.
Atlases are kept outside public so the game downloads only individual sprites.

Versioned v3/v4 asset paths prevent cached older illustrations from mixing with
new redraws. Normal npm builds use the committed files and need no image/audio tools.
src/faces.ts records newly measured head regions for opening protection, and
review/faces.html exposes those regions for visual inspection.

Existing level 1–5 character artwork and UI artwork remain in their original
paths. Chapter 1 and 4 small enemies were redrawn with lighter body planes and
readable pale/lavender and rose/gold palettes respectively. Their five-sprite
atlases are art/early/{1,4}-sprites-v3.webp; package with
node scripts/pack-enemy-sprites.mjs --early. The sixth atlas cell is empty and
the existing bosses are preserved. Runtime sprites live in levels/{1,4}/v3.
Earlier files remain available for already-open clients; LEVELS selects the
current character/supporting assets and enemy sprites independently.

Player and dialog update
------------------------
art/ui/player-spirit-atlas.webp is the generated transparent 2 × 2 source atlas
for the golden spirit flame (no animal features). scripts/pack-player-spirit.mjs
aligns each bright core using its weighted pixel centroid, translates without
cropping visible pixels, and uniformly packages four 128 × 128 cells into
public/sprites/player-spirit.webp. Run with Node, ffprobe and ffmpeg. The runtime
uses the fixed center anchor and 6 frames per second; no collision rule changes.

public/ui/torn-parchment.webp is a newly generated solid blank aged sheet with
transparent irregular tears on all four edges. Dialogs use a nine-slice with
center fill and no opaque rectangular background, keeping the tears transparent
on both narrow portrait and wide landscape layouts. Existing title and board
artwork keep their original paths. Both additions were generated for this game.

scripts/export-art-review.mjs reads the current level catalog and exports the
30 reward images and 60 enemy images, plus a four-frame player preview. Normal
development/build writes linked review pages; --offline additionally embeds
the exact current files into two portable HTML files for art review.
